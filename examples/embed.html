Renew, embedded in a web page

This page does not contain the Renew interpreter. It imports renewal-2026.mjs, the ES module that renew compile examples/01-renewal-2026.renew --module produced, calls run() and draws the result.

The one input

Type it with its unit, like 1.5%. The same discount is taken off the posted 1 and 5 year rates.

Lock in for 5 years, or take 1 year and decide?

The same figures as a table, from the raw numbers run() returns.
PlanPaymentInterest over 5 yearsBalance after 5 years

The 1 year offer is assumed to renew at its current rate for the rest of the 5 years. Posted rates are Bank of Canada benchmarks, not quotes. A plan, not a forecast.

The code that draws it

import { run, inputs } from "./embed/renewal-2026.mjs";
const result = run({ discount: "1.5%" });
const table = result.blocks.find((b) => b.kind === "table" && b.title.startsWith("Compare"));
// table.columns, table.raw (numbers) and table.units ("money", "duration", ...)
const breakEven = result.blocks.find((b) => b.text && b.text.startsWith("break even"));
// breakEven.value is 4.889 and breakEven.type is "percent"
